== Description ==


This block plugin makes the displays fully customizable, so you can create unique team showcases for your site. This is the best WordPress team plugin that displays in a fantastic way of your team members on your site. It is 100% responsive and mobile-friendly, which guarantees the best views across all devices.

== Installation ==

= From Gutenberg Editor: =
1. Go to the WordPress Block/Gutenberg Editor
2. Search For **Team Section**
3. Click on the **Team Section** block to add the block

= Download & Upload: =
1. Download the **Team Section** plugin (*.zip file*)
2. In your admin area, go to the Plugins menu and click on **Add New**
3. Click on **Upload Plugin** and choose the **`team-section.zip`** file and click on **Install Now**
4. Activate the plugin and Enjoy!

= Manually: =
1. Download and upload the **Team Section** plugin to the **`/wp-content/plugins/`** directory
2. Activate the plugin through the Plugins menu in WordPress
